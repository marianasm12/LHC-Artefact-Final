# LHC Artefact Management System

A Python console application developed for the ACCA5036 Scripting and
Programming Concepts assessment (UWTSD). It allows volunteers to manage
the artefact collection through a ten-option menu.

## Features
1. View All Artefacts
2. Add New Artefact
3. Search Artefact by Name
4. Update Artefact Condition
5. Relocate Artefact
6. Record Artefact Notes
7. View Artefacts Requiring Attention
8. Create Collection Summary
9. Remove Artefact
10. Exit System

The program starts with ten sample artefact records. Records are stored
in memory only, so changes are lost when the program closes.

## How to run
Requires Python 3 (tested with Python 3.14). No external packages are needed.

    python lhc_artefact_system.py
